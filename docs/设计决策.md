# TraceForge 视觉与交互决策

面向研发人员排查故障，主界面直接提供报错输入、近期任务和执行证据。标志以收拢的流程分支表现“追踪证据”，不使用营销首页。

- 颜色：纸白 #f7f8fc、纯白 #ffffff、墨蓝 #25314b、靛蓝 #4351d6、证据青 #198c8b、告警琥珀 #a96c17。
- 字体：中文使用系统 Microsoft YaHei / PingFang SC，标题紧凑；英文和数字使用系统 Segoe UI；日志使用 Cascadia Code。无需外部字体下载。
- 布局：窄侧栏 / 弹性工作区 / 可折叠证据检查器；内容左对齐，诊断稿保持可阅读的行宽。
- 重点：诊断任务的时间线与真实执行图。知识和评估页使用表格及实验结果，避免把所有内容堆成同样的卡片。
- 交互：审批明确展示动作和文件差异；错误给出修复入口；键盘焦点、移动端布局和 reduced motion 保留。

方案复核：采用蓝灰工作台语汇，强调故障证据和执行记录。仅状态徽标、操作区与引用条目使用不同层级的圆角，不使用装饰渐变和夸大数据。
